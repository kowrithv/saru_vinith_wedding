**Goal:** Die echte Startseite (`/`) statt des Platzhalters aus dem
Foundation-Plan: Hero mit Namen/Datum/CTAs, Live-Countdown zum Empfang,
und ein Kachel-Raster, das zu jeder anderen Seite verlinkt.

**Architecture:** Drei neue Komponenten (`Hero`, `Countdown`,
`FeatureGrid`), komponiert in `src/app/page.tsx`. Inhalte direkt im Code
(`src/lib/home-content.ts` für die Kacheln, `receptionEvent` aus dem
bestehenden `event-info.ts` für Datum/Ort). `Countdown` tickt clientseitig
und zeigt bis zum ersten Mount ein Skeleton statt einer Zahl - sonst
bekäme jeder Erstbesucher eine andere Server- als Client-Zahl gebacken
(exakt dieselbe Hydration-Fallklasse wie der Memory-Spiel-Bug aus dem
Quiz-Review, hier mit der alten App's bereits bewährter
Mounted-Flag-Lösung statt `next/dynamic`, weil nur eine Zahl abweicht,
nicht eine ganze zufällige Kartenzuordnung).

**Tech Stack:** Next.js App Router · React 19 · Tailwind v4 (Theme aus dem
Design-System-Plan) · framer-motion · lucide-react · Vitest + React
Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-11-rewrite-design.md`

## Global Constraints

- Inhalte 1:1 aus der alten Seite übernommen (als Text, nicht als Code).
  Die alte Startseite hatte zusätzlich eine "Story-Teaser"- und eine
  doppelte "Wedding-Info-Karten"-Sektion, die beide bereits bestehende
  Seiten (`/story`, `/info`) inhaltlich duplizieren - hier bewusst
  weggelassen zugunsten eines einzigen Kachel-Rasters zu allen Seiten
  (entspricht der alten App's "Entdeckt unsere Website"-Sektion).
- **Kein Tab für die tamilische Hochzeit 2027** (`showTraditionalWeddingTab`
  war in der alten App schon per Konstante deaktiviert) - exakt dieselbe
  bereits getroffene Entscheidung wie im Hochzeitsinfos-Plan.
- `Galerie` ist im Kachel-Raster enthalten (wie in der bestehenden
  Navigation), obwohl `/gallery` noch nicht existiert (blockiert auf
  R2-Zugangsdaten, `TODO.md`) - konsistent mit der bereits bestehenden
  Navigation, die denselben Verweis schon enthält.
- `Button` bekommt eine neue optionale `href`-Prop (rendert dann einen
  `Link` statt eines `<button>`). Ohne das würde Hero's CTA ein
  `<button>` in ein `<a>` verschachteln (`<Link><Button>...`) - ungültiges
  HTML (interaktiver Inhalt darf nicht in interaktivem Inhalt stecken),
  dieselbe Fehlerklasse, die im Design-System-Plan bei verschachtelten
  `<main>`-Landmarks schon einmal gefunden wurde.
- TDD ist Pflicht für jede Komponente/Funktion mit eigener Logik.
  `Hero`/`FeatureGrid` sind reine Darstellung ohne eigene Logik - sie
  bekommen trotzdem einen Rendering-Test pro Komponente.

## Review Focus

- `Countdown` darf vor dem ersten Mount keine konkrete Zahl rendern (nur
  ein Skeleton) - sonst driftet die serverseitig gerenderte Zahl
  (Build-/Request-Zeitpunkt) von der tatsächlichen Client-Uhrzeit
  auseinander und erzeugt einen Hydration-Mismatch.
- Ist der Empfangstermin bereits vergangen, muss `Countdown` die
  Glückwunsch-Meldung zeigen, nicht negative oder stehengebliebene Werte.
- Jede Kachel im Feature-Grid muss auf eine tatsächlich existierende
  Route verlinken - mit der einzigen, bereits dokumentierten Ausnahme
  Galerie (`/gallery`, blockiert auf R2).
- Hero's CTA-Buttons müssen clientseitige Next.js-Navigation sein
  (`next/link`), kein `<button>` verschachtelt in einem `<a>`.
- Die Startseite trägt ihre eigene Außenhülle wie jede andere Seite,
  aber `Hero` ist die einzige Ausnahme von der `pt-24`-Konvention: sie
  ist `min-h-screen` und zentriert ihren Inhalt selbst - ein zusätzliches
  `pt-24` von außen würde sie nicht mehr bildschirmfüllend zentrieren.

```ts
// src/lib/utils.ts (vollständige neue Fassung)
import { clsx, type ClassValue } from 'clsx'
import { twMerge } from 'tailwind-merge'

export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs))
}

export interface TimeUntil {
  days: number
  hours: number
  minutes: number
  seconds: number
  isPast: boolean
  total: number
}

export function calculateTimeUntil(targetDate: string, targetTime?: string): TimeUntil {
  const now = new Date()
  const target = new Date(`${targetDate}T${targetTime ?? '00:00'}:00`)
  const diff = target.getTime() - now.getTime()

  if (diff <= 0) {
    return { days: 0, hours: 0, minutes: 0, seconds: 0, isPast: true, total: 0 }
  }

  const days = Math.floor(diff / (1000 * 60 * 60 * 24))
  const hours = Math.floor((diff % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60))
  const minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60))
  const seconds = Math.floor((diff % (1000 * 60)) / 1000)

  return { days, hours, minutes, seconds, isPast: false, total: diff }
}
```

```tsx
// src/components/ui/Button.tsx (vollständige neue Fassung)
import type { ReactNode } from 'react'
import Link from 'next/link'
import { cn } from '@/lib/utils'

interface ButtonProps {
  children: ReactNode
  onClick?: () => void
  href?: string
  type?: 'button' | 'submit'
  variant?: 'primary' | 'secondary'
  size?: 'sm' | 'md' | 'lg'
  disabled?: boolean
  className?: string
}

const sizeClasses = {
  sm: 'px-4 py-2 text-sm',
  md: 'px-5 py-2.5 text-sm',
  lg: 'px-6 py-3 text-base',
}

const variantClasses = {
  primary: 'bg-dark-blue text-white hover:bg-dark-blue-light shadow-md hover:shadow-lg',
  secondary: 'border-2 border-dark-blue text-dark-blue hover:bg-dark-blue hover:text-white',
}

export default function Button({
  children,
  onClick,
  href,
  type = 'button',
  variant = 'primary',
  size = 'md',
  disabled = false,
  className,
}: ButtonProps) {
  const classes = cn(
    'inline-flex items-center justify-center gap-2 font-medium rounded-full transition-all duration-200 active:scale-[0.98] disabled:opacity-50 disabled:cursor-not-allowed disabled:active:scale-100',
    sizeClasses[size],
    variantClasses[variant],
    className
  )

  if (href) {
    return (
      <Link href={href} className={classes}>
        {children}
      </Link>
    )
  }

  return (
    <button type={type} onClick={onClick} disabled={disabled} className={classes}>
      {children}
    </button>
  )
}
```

```tsx
      <div className="w-1 h-1 bg-dark-blue rounded-full" />
      <div className="w-1 h-1 bg-dark-blue rounded-full" />
    </div>
  )
}

export default function Countdown() {
  const [timeLeft, setTimeLeft] = useState({ days: 0, hours: 0, minutes: 0, seconds: 0, isPast: false })
  const [mounted, setMounted] = useState(false)

  useEffect(() => {
    setMounted(true)

    const update = () => {
      setTimeLeft(calculateTimeUntil(receptionEvent.date, receptionEvent.rawTime))
    }

    update()
    const interval = setInterval(update, 1000)
    return () => clearInterval(interval)
  }, [])

  return (
    <section className="py-16 md:py-20 bg-gradient-to-b from-white to-champagne-light/30">
      <div className="max-w-4xl mx-auto px-4 sm:px-6 text-center">
        <div className="mb-10">
          <div className="inline-flex items-center gap-2 text-gold text-sm font-medium mb-3">
            <Clock size={16} />
            <span>Noch so lange bis zum großen Tag</span>
          </div>
          <h2 className="font-serif text-3xl md:text-4xl font-semibold text-dark-blue">Countdown zum Empfang</h2>
          <p className="mt-2 text-gray-500 text-sm">
            {receptionEvent.displayDate} um {receptionEvent.time}
          </p>
        </div>

        {!mounted ? (
          <div className="h-40 animate-pulse bg-champagne/30 rounded-2xl" />
        ) : timeLeft.isPast ? (
          <div className="py-12">
            <p className="font-serif text-4xl text-dark-blue font-semibold">Wir sind verheiratet! 🎉</p>
            <p className="mt-4 text-gray-600">{receptionEvent.displayDate} – Ein Tag, den wir nie vergessen werden</p>
          </div>
        ) : (
          <div className="flex items-center justify-center gap-3 sm:gap-6 md:gap-8">
            <CountdownUnit value={timeLeft.days} label="Tage" delay={0} />
            <Separator />
            <CountdownUnit value={timeLeft.hours} label="Stunden" delay={0.1} />
            <Separator />
            <CountdownUnit value={timeLeft.minutes} label="Minuten" delay={0.2} />
            <Separator />
            <CountdownUnit value={timeLeft.seconds} label="Sekunden" delay={0.3} />
          </div>
        )}

        <p className="mt-10 text-xs text-gray-400 font-medium tracking-wide">
          {receptionEvent.venue} · {receptionEvent.address}
        </p>
      </div>
    </section>
  )
}
```
